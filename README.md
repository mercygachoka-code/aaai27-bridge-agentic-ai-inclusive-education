# Bridge 21: AI for Inclusive Education
## AAAI-27 Bridge Program (16–17 February 2027, Montréal, Canada)

**Title:** Co-Designing Agentic AI with K–12 Teachers Supporting Learners with Specific Learning Disorders in Low-Resource Settings

---

### Project Stack
- **Framework:** React 19 + Vite 6
- **Styling:** Tailwind CSS + Custom Design System
- **Animation:** Framer Motion (page transitions, stagger fade-ins, ambient organic motion)
- **Icons:** Lucide React
- **Typography:** Playfair Display (academic elegance) + Inter (readability & WCAG compliance)
- **Palette:** Deep Indigo (`#243B6B`), Teal (`#159A9C`), Warm Gold (`#F2B84B`), Soft White / Cream (`#FAFBFD` / `#F4F6FA`)

---

### Running the Project Locally
To install and run the development server:

```bash
git clone https://github.com/mercygachoka-code/aaai27-bridge-agentic-ai-inclusive-education
```

```bash
cd aaai27-bridge-agentic-ai-inclusive-education
```
```bash
npm install
```

```bash
npm run dev
```

To build for production:
```bash
npm run build
```

To preview production build:
```bash
npm run preview
```
